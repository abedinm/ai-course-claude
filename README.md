# Claude Interactive AI Course

One self-contained, offline-capable HTML course about **Claude (Anthropic)**.

## Open the Course

- GitHub Pages: https://abedinm.github.io/ai-course-claude/
- Local: open `index.html` in any modern browser.

## Features

- Single-file HTML app with inline CSS, JavaScript, content, and PWA metadata
- Works online and offline after first browser load, and also opens directly as a local file
- Animated particle/starfield background
- XP, levels, streaks, lessons completed, achievements, and leaderboard
- Three locked/unlocked learning modules
- Learn, quiz, and sandbox tabs in every module
- Prompt simulator with chip templates and typewriter output
- localStorage progress persistence
- Responsive layout for desktop, tablet, and mobile
- No CDN, no remote scripts, no external fonts

## Course Focus

Constitutional AI, safety, long context, and document analysis
